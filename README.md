# Social Media API

RESTful API для социальной сети, реализованное на Spring Boot.  
Проект позволяет пользователям регистрироваться, публиковать посты, взаимодействовать друг с другом и получать персонализированную ленту активности.

---

## Технологии

- Java 17
- Spring Boot 3
- Spring Security
- JWT (JSON Web Token)
- Spring Data JPA
- PostgreSQL
- Liquibase
- Swagger / OpenAPI
- Lombok
- JUnit / AssertJ

---

## Основной функционал

### Аутентификация и авторизация
- Регистрация пользователя (username, email, password)
- Вход в систему (JWT)
- Хэширование паролей
- Защита эндпоинтов через Spring Security

---

### Посты
- Создание поста (заголовок, текст, изображения)
- Просмотр постов
- Обновление своих постов
- Удаление своих постов

---

### Социальные взаимодействия
- Отправка заявки в друзья
- Подписки (followers)
- Принятие / отклонение заявки
- Логика:
  - отправитель заявки = подписчик
  - при принятии → оба становятся друзьями
  - при удалении из друзей → один отписывается, второй остается подписчиком

---

### Сообщения
- Отправка сообщений между друзьями
- Получение переписки (без realtime-чата)

---

### Лента активности
- Отображение постов пользователей, на которых есть подписка
- Сортировка по дате
- Пагинация

---

###  Обработка ошибок
- Валидация входных данных
- Понятные сообщения об ошибках
- Обработка исключений (GlobalExceptionHandler)

---

### Документация API
- Swagger UI доступен после запуска приложения:
- http://localhost:8080/swagger-ui.html

## Конфигурация (уже настроена)

Проект уже содержит готовый application.properties, поэтому ничего дополнительно настраивать не нужно.

### База данных
spring.datasource.url=jdbc:postgresql://localhost:5432/social_media_api_new
spring.datasource.username=postgres
spring.datasource.password=password

### Требование:
Нужно только создать базу данных:

CREATE DATABASE social_media_api_new;

## JWT
jwt.token.secret=***
jwt.token.expired=3600000

Используется для аутентификации

Время жизни токена: 1 час

## Запуск проекта
mvn spring-boot:run

После запуска приложение будет доступно по адресу:

http://localhost:8080

## Аутентификация

1. Получить JWT токен через endpoint авторизации

2. Передавать его в каждом запросе:

Authorization: Bearer <token>
